<!-- alaws:commentary -->

How an incident's severity is assigned and revised.

<!-- alaws:laws -->

1. An incident that causes customer-visible data loss must be classified Severity 1 regardless of the number of customers affected.

2. Severity classification must be reassessed if new information changes the blast radius, not fixed at first report.

3. Agents must not downgrade a severity level without a human confirming the downgrade.
