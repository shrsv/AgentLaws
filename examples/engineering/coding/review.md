<!-- alaws:commentary -->

Rules for how a code change gets reviewed before it merges.

<!-- alaws:laws -->

1. Every change to {{repo}} must be reviewed by at least one human, {{reviewer}} or another qualified reviewer, before merging.

2. An agent must not approve its own pull request.

3. Review comments that request a change must be resolved or explicitly declined with a rationale before merge.
